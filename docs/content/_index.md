# Fitness Tracker

A complete fitness tracking web application with user authentication, workout management, session tracking, and weight tracking.

## Features

- **User Authentication** - Register, login, and secure token-based auth using Laravel Sanctum
- **Workout Management** - Create and manage workout types (e.g., Bench Press, Squats)
- **Session Tracking** - Log workout sessions with sets, reps, and weights
- **Weight Tracking** - Track body weight over time

## Tech Stack

- **Backend**: Laravel 12, PHP 8.2
- **Database**: SQLite
- **Authentication**: Laravel Sanctum
- **Frontend**: Vanilla JavaScript
- **Containerization**: Docker
- **Documentation**: Hugo
